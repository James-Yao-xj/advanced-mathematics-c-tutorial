用于高等数学 C 小班课的讲义与课后习题，按知识点整理，供课堂讲授、演算和课后练习使用。

当前内容对应周建莹、张锦炎《高等数学（生化医农类，上）》前三章：

1. 微积分的准备知识：函数、极限与连续。
2. 微商与微分：导数、隐函数与参数方程、高阶导数、微分。
3. 微分中值定理及其应用：单调性、极值、凹凸性、洛必达法则、泰勒公式与牛顿法。

讲义含 55 道课堂真题例题与 12 道课后习题，选自高等数学 B、C 往年题。核心知识以黄色高亮标出，题后留有演算空间，不附解析。题目来源简注于页脚。

另附独立的配套解析，共 17 页，按原题号覆盖全部 55 道例题与 12 道课后习题。解答使用红色，包含原题条件不足处的反例与修正说明。课堂讲义与解析分别维护。

## 第二次课：有理函数与有理化积分

- [课程主页](https://james-yao-xj.github.io/advanced-mathematics-c-tutorial/)
- [第二次课讲义 · PDF](handouts/高等数学C-第二次课讲义.pdf)
- [第二次课讲义 · Typst 源文件](handouts/高等数学C-第二次课讲义.typ)

共 13 页，先阅读教材第四章 §5—§7（第 177—193 页）梳理知识，再按知识点匹配题目，依次讲授：

1. 有理函数的积分：化真分式、部分分式分解与四类基本积分。
2. 三角函数有理式的积分：万能变换、正切换元、积化和差与奇偶幂处理。
3. 几种简单的代数无理式的积分：一次根式、一次分式根式与二次根式。

含 13 道课堂例题和 9 道课后习题，共 22 道，其中 11 道为 B、C 往年题，11 道取自教材例题或习题；重复考题合并标注，C 2021 保留回忆版标注。核心知识黄色高亮，题目转写为文字和公式，保留作答空间，不附解析。

## 编辑与编译

使用 Typst 编辑 `.typ` 文件；需要可用的中文字体。首次编译会获取 `@preview/ctyp:0.3.0` 排版依赖。

```sh
typst compile handouts/高等数学BC-前三章讲义.typ handouts/高等数学BC-前三章讲义.pdf
```
