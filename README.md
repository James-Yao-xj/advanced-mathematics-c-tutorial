# 高等数学 C 小班课资料

用于高等数学 C 小班课的讲义与课后习题，按知识点整理，供课堂讲授、演算和课后练习使用。

## 讲义

- [前三章讲义 · PDF](handouts/高等数学BC-前三章讲义.pdf)
- [前三章讲义 · Typst 源文件](handouts/高等数学BC-前三章讲义.typ)
- [配套解析 · PDF](handouts/高等数学BC-前三章配套解析.pdf)
- [配套解析 · Typst 源文件](handouts/高等数学BC-前三章配套解析.typ)

当前内容对应周建莹、张锦炎《高等数学（生化医农类，上）》前三章：

1. 微积分的准备知识：函数、极限与连续。
2. 微商与微分：导数、隐函数与参数方程、高阶导数、微分。
3. 微分中值定理及其应用：单调性、极值、凹凸性、洛必达法则、泰勒公式与牛顿法。

讲义含 55 道课堂真题例题与 12 道课后习题，选自高等数学 B、C 往年题。核心知识以黄色高亮标出，题后留有演算空间，不附解析。题目来源简注于页脚。

另附独立的配套解析，共 17 页，按原题号覆盖全部 55 道例题与 12 道课后习题。解答使用红色，包含原题条件不足处的反例与修正说明。课堂讲义与解析分别维护。

## 编辑与编译

使用 Typst 编辑 `.typ` 文件；需要可用的中文字体。首次编译会获取 `@preview/ctyp:0.3.0` 排版依赖。

```sh
typst compile handouts/高等数学BC-前三章讲义.typ handouts/高等数学BC-前三章讲义.pdf
```

## 题干与解析复核

已逐题复核全部 67 题，并对导数、极限和泰勒系数完成 50 项独立符号或高精度计算检查。本次修正：

- 例 36：原题为 $|f(x)|\le\ln(1+|\arcsin x|)$，绝对值位于对数内。
- 课后习题 5：原题为三层幂 $y=x^{x^{x^3}}$，已补回漏写的一层并重写求导。
- 课后习题 12：讲义明确标注原命题条件缺漏；解析保留反例及补充 $AB\ge0$ 后的证明。

讲义与配套解析分别为 29 页、17 页；两者的 PDF 和 Typst 源文件均已同步修正。

## 课程主页

主页仅展示资料目录。点击讲义或配套解析卡片，即可打开对应 PDF。

- 网页入口：`index.html`；样式位于 `assets/`，无需安装依赖。
- 本地预览：在仓库目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000`。
- 首次发布：进入仓库 **Settings → Pages → Build and deployment**，将 Source 设为 **GitHub Actions**。合并主页改动到 `main` 后，工作流自动发布；也可在 Actions 中手动运行 **Deploy course homepage**。
- 发布地址：<https://james-yao-xj.github.io/advanced-mathematics-c-tutorial/>。

后续更新 `main` 中的网页或 PDF 会自动重新发布。网站只发布网页资源与 PDF；Typst 源文件仍在仓库提供。
